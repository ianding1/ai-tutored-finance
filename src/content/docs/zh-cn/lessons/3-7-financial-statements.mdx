## 三张报表 [#three-statements]

要给股票估值，先要读懂公司的财务报表。美国上市公司每季度提交 10-Q、每年提交 10-K 报告，其中的财务报表按美国通用会计准则（GAAP）编制。最重要的是三张报表。

<Def id="balance-sheet">资产负债表</Def>（balance sheet）列出某一时点公司拥有什么（资产 $A$）、欠别人什么（负债 $L$），以及剩下归股东的部分（股东权益 $E$）：

$$
A = L + E
$$

资产包括现金、应收账款、存货、厂房设备等；负债包括应付账款、借款、债券等；股东权益主要是股东投入的资本和历年留下的利润（留存收益）。

<Def id="income-statement">利润表</Def>（income statement）记录一段时期（一个季度或一年）的收入和费用。下面是一个简化的例子：

| 项目 | 金额 |
| --- | ---: |
| 收入 | 1,000 |
| 减：销售成本 | 600 |
| 毛利 | 400 |
| 减：销售、管理和研发费用 | 200 |
| 减：折旧 | 50 |
| 营业利润（EBIT） | 150 |
| 减：利息 | 30 |
| 税前利润 | 120 |
| 减：所得税（税率 21%） | 25.2 |
| 净利润 | 94.8 |

利润表按<Def id="accrual-accounting">权责发生制</Def>（accrual accounting）编制：收入在交付商品或服务时确认，即使客户还没有付款；费用与相关的收入在同一时期确认，即使现金早就付出或还没有付出。例如，公司花 500 买一台用 10 年的机器，不会在买入的那一年把 500 全部算作费用，而是每年确认 50 的<Def id="depreciation">折旧</Def>（depreciation）。折旧是费用，但不是当年的现金支出。

会计利润和 <Ref concept="economic-profit" /> 不同：会计利润只扣除了借款的利息，没有扣除股东资本的机会成本（<Ref concept="cost-of-capital" />）。

<Def id="cash-flow-statement">现金流量表</Def>（cash flow statement）记录一段时期现金的实际收支，分为三类：

- 经营活动：日常经营收到和付出的现金；
- 投资活动：购买和出售厂房设备、收购其他公司、买卖投资；
- 筹资活动：借款和还款、发行和回购股票、支付股息。

## 报表之间的联系 [#linkages]

三张报表是同一组交易的不同角度，它们之间有严格的勾稽关系：

- 净利润使股东权益增加：期末留存收益 = 期初留存收益 + 净利润 − 股息。
- 现金流量表三类现金流的合计，等于资产负债表上现金的变化。
- 经营活动现金流可以从净利润出发推出（间接法）：加回折旧等不付现金的费用，再减去<Def id="working-capital">营运资本</Def>（working capital）的增加。营运资本主要是应收账款加存货减应付账款：应收账款增加，说明一部分收入还没有收到现金；存货增加，说明付了现金买的货还没有卖出；应付账款增加，说明一部分费用还没有付现金。

$$
\text{CFO} = \text{NI} + \text{Dep} - \Delta \text{WC}
$$

其中 CFO 是经营活动现金流，NI 是净利润，Dep 是折旧，$\Delta \text{WC}$ 是营运资本的增加。

## 盈余质量 [#earnings-quality]

权责发生制使利润更好地反映一段时期的经营成果，但也要求大量的估计和判断：机器能用几年、应收账款中有多少收不回来、存货是否已经贬值、一份多年的合同在各期确认多少收入。这些估计合理时，利润比现金流更能反映经营；估计过于乐观时，利润就会被高估。

报告的利润在多大程度上反映可持续的、最终能变成现金的经营成果，叫<Def id="earnings-quality">盈余质量</Def>（earnings quality）。常用的检查方法有：

- 比较净利润和经营活动现金流：长期中两者应该接近；利润持续明显高于现金流，要找出原因。
- 看应收账款和存货的增长是否明显快于收入。
- 看会计估计和会计政策的变更，以及它们对利润的影响（年报附注中会说明）。
- 区分可持续的利润和一次性的项目（出售资产的收益、诉讼和解等）。

利润表上的数字并不都是同样“硬”的。会计估计的一个小变化，就可能使利润明显变化，而现金流完全不变（<Ref check="C3" />）。

## 常见的会计美化 [#red-flags]

管理层的薪酬和声誉常与报告的利润挂钩，这是 <Ref concept="principal-agent-problem" /> 的又一个例子。常见的美化手法有：

- 提前确认收入：例如季末向经销商大量压货（channel stuffing），收入增加，应收账款增加得更快。
- 把费用资本化：把本应计入当期费用的支出记为资产，以后再分年摊销，当期利润增加。
- 调整估计：延长资产的使用年限、减少坏账准备，或者在好年份多计提准备、在差年份释放（“饼干罐”）。
- 反复出现的“一次性”费用：每年都有重组费用，却每年都要求投资者把它排除在外。
- 强调“调整后”的利润：公司常在 GAAP 利润之外报告非 GAAP 利润，剔除股票薪酬、摊销、重组费用等项目，调整后的利润往往明显高于 GAAP 利润。

这些手法大多不违法，有的还有合理的理由，但它们会使利润与现金流的差距扩大，并且在以后的年份反转。分析时要回到现金流，并读年报的附注。

## 小结 [#summary]

- 资产负债表：资产 = 负债 + 股东权益；利润表：一段时期的收入、费用和净利润；现金流量表：经营、投资和筹资活动的现金收支。
- 权责发生制按交付和配比确认收入和费用；折旧把长期资产的成本分摊到使用年限，不是当期现金支出。
- 净利润进入留存收益；三类现金流的合计等于现金的变化；经营活动现金流 = 净利润 + 折旧 − 营运资本的增加。
- 盈余质量看利润在多大程度上是可持续的、能变成现金的；要比较利润和现金流，注意估计的变更、一次性项目和“调整后”的利润。
