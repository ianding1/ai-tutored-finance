## 公式表 [#formulas]

**现值与利率**

- 年金（每期期末付款 $C$，共 $n$ 期）：$PV = \frac{C}{r}\left[1 - (1 + r)^{-n}\right]$；增长永续年金：$PV = \frac{C}{r - g}$
- Fisher 方程：$1 + r = \frac{1 + i}{1 + \pi}$

**债券**

- 价格：$P = \sum_{t=1}^{T} \frac{\text{CF}_t}{(1 + y)^t}$
- 修正久期与凸性：$\frac{\Delta P}{P} \approx -D^*\Delta y + \frac{1}{2}C(\Delta y)^2$，$D^* = \frac{D}{1 + y}$

**股票与公司估值**

- Gordon 模型：$P_0 = \frac{D_1}{r - g}$；动态市盈率：$\frac{P_0}{E_1} = \frac{1 - b}{r - g}$（$b$ 为留存比率）
- $\text{WACC} = \frac{E}{V}r_E + \frac{D}{V}r_D(1 - t)$
- 积木法：$E[R] \approx y + g + \pi + \Delta v$（股东收益率、每股盈利实际增长、通胀、估值变化）

**风险与组合**

- 两项资产组合的方差：$\sigma_p^2 = w^2\sigma_A^2 + (1 - w)^2\sigma_B^2 + 2w(1 - w)\rho\sigma_A\sigma_B$
- CAPM：$E[R_i] = r_f + \beta_i(E[R_M] - r_f)$，$\beta_i = \frac{\text{Cov}(R_i, R_M)}{\text{Var}(R_M)}$
- 夏普比率：$\frac{\mu - r_f}{\sigma}$；最优风险资产比例：$w^* = \frac{\mu - r_f}{\gamma\sigma^2}$
- 长期复合增长率：$g \approx \mu - \frac{\sigma^2}{2}$
- 样本均值的标准误：$\frac{\sigma}{\sqrt{n}}$；alpha 的 t 值：$t \approx IR\sqrt{T}$
