## 公式表 [#formulas]

**现值与利率**

- 年金（每期期末付款 $C$，共 $n$ 期）：$PV = \frac{C}{r}\left[1 - (1 + r)^{-n}\right]$；增长年金（第一期付款 $C$，每期增长 $g$）：$PV = \frac{C}{r - g}\left[1 - \left(\frac{1 + g}{1 + r}\right)^n\right]$
- Fisher 方程：$1 + r = \frac{1 + i}{1 + \pi}$

**远期、期货与互换**

- 持有成本模型：$F = S e^{(r - q)T}$
- 抛补利率平价（汇率为每单位外币的本币价格）：$F = S \left(\frac{1 + i_d}{1 + i_f}\right)^T$
- 最小方差对冲比率：$h^* = \rho\frac{\sigma_S}{\sigma_F}$
- 互换利率（$Z_t$ 为 $t$ 年期的折现因子）：$s = \frac{1 - Z_n}{\sum_{t=1}^{n} Z_t}$

**期权**

- 看涨–看跌平价：$C - P = S - K e^{-rT}$
- Black–Scholes：$C = S\,N(d_1) - K e^{-rT} N(d_2)$，$d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}$，$d_2 = d_1 - \sigma\sqrt{T}$

**基金与家庭投资**

- 费用使 $T$ 年后的期末财富减少的比例：$\approx 1 - e^{-fT}$
- 资金充足率 $=$ 为目标准备的资产 $/$ 目标按无风险利率折现的现值
- 两项资产组合的方差：$\sigma_p^2 = w^2\sigma_A^2 + (1 - w)^2\sigma_B^2 + 2w(1 - w)\rho\sigma_A\sigma_B$
- 夏普比率：$\frac{\mu - r_f}{\sigma}$；alpha 的 t 值：$t \approx IR\sqrt{T}$
